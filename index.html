How to get and install the APK
  1. Tap Copy one-file APK build.
  2. On github.com create a repository, then Add file → Create new file. Name it .github/workflows/build.yml, paste, and Commit.
  3. Wait about 4 minutes. Open Releases (or the run's Artifacts) and download the .apk.
  4. Open the APK, allow Install unknown apps for Chrome or Files, then tap Install.

PWA: unzip the PWA package onto any HTTPS host (GitHub Pages, Netlify, Cloudflare Pages), open it in Chrome, then ⋮ → Install app. Chrome makes the app and assigns its own package name.

Android Studio: open the project zip and run Build → Build APK.
